# 📅 Öğrenci Ders Programı

Öğrencilerin haftalık ders programlarını ve ders detaylarını kolayca görüntüleyebilmeleri için geliştirilmiş React Native mobil uygulaması.

## 🚀 Özellikler
- **Ders Listesi:** `FlatList` ve özel `CourseCard` bileşeni kullanılarak dinamik ders listeleme.
- **Ders Detayı:** Derslik, öğretmen ve saat bilgilerini içeren detay ekranı (`ders/[id].jsx`).
- **Gezinti:** Expo Router ile akıcı ekranlar arası geçiş.

## 🛠️ Kullanılan Teknolojiler
- React Native
- Expo Router
- JavaScript (ES6+)
